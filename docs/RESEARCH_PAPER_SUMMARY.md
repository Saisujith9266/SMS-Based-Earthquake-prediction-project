# Research Paper Summary

The project proposes a machine-learning framework for earthquake magnitude prediction using latitude, longitude, depth, time and seismic measurements.

## Models
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. XGBoost
5. Artificial Neural Network (ANN)

## Metrics
MAE, MSE, RMSE and R² Score.

## Methodology
Dataset Collection → Data Cleaning → Missing-Value Handling → Feature Selection → Normalization → Train/Test Split → Model Training → Magnitude Prediction → Evaluation → Risk Classification → Alert/Dashboard.

## Research Gap
The proposed system combines multi-model magnitude prediction with a practical response layer: predicted magnitude → risk level → affected area → SMS alert.

The paper states that final numerical model-performance values must be obtained from completed experiments; this repository does not fabricate them.
